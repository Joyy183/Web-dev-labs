RUN
Open index.html in any modern browser. Keep app.js and style.css beside it.
No installation or build step is needed to run the supplied JavaScript.

FEATURES
Add tasks with Add or Enter; mark tasks complete; double-click to edit.
Enter saves an edit. Escape cancels it. Blank tasks are ignored.
Filter All / Active / Completed; delete one task; clear completed or all tasks.
The remaining count always counts all active tasks.
Tasks are stored in memory and reset on refresh.
